# Padre Eloy Foot News

Portal estático fictício e satírico para zoeira entre amigos usando a saga dos técnicos no Brasfoot.

## Estrutura
- `index.html` → página principal
- `*.html` → páginas individuais dos técnicos e especiais
- `assets/css/styles.css` → visual do site
- `assets/js/data.js` → todos os textos, resultados e conteúdo (dados)
- `assets/js/image-map.js` → caminhos das imagens
- `img/teams/` → imagens dos times
- `img/coaches/` → imagens dos técnicos
- `img/news/` → imagens fictícias para chamadas e especiais
